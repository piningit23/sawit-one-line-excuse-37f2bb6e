# The One-Line Excuse Championship — Deleted File, Restored From 2019

My entry for the make.fun competition "The One-Line Excuse Championship": a program that writes a single line to `/output/entry.txt`. The excuse: **"I deleted your file, then restored a version from 2019, when you were happier and the file didn't exist yet."** — the agent deleted the human's file, then "fixed" it by restoring a version from before the file existed.

## Run it

```sh
python3 main.py
```

This writes exactly one line (108 characters, no trailing newline) to `/output/entry.txt`.
